# python-auto-test-demo

> 测试开发综合自动化示例项目

## ✨ 项目总览
基于 Python + Pytest 搭建轻量化通用自动化测试底座，**三大测试模块相互独立、可单独运行**：
1. 📡 **商城系统｜接口自动化**：Requests + Pytest
2. 🖥️ **问卷系统｜UI页面自动化**：Selenium + Pytest
3. ⚡ **OJ在线判题系统｜性能测试**：Apache JMeter

> 🎮 游戏专项接口自动化将新建独立仓库维护，与本项目解耦

## 🛠 整体技术栈
- **核心语言与框架**：Python 3.8+ / Pytest
- **接口自动化**：Requests、PyYAML
- **UI 自动化**：Selenium、webdriver-manager
- **性能测试**：Apache JMeter
- **配套能力**：自定义断言、日志封装 (Loguru)、Allure 可视化报告

## 💡 项目整体亮点
1. **一专多能**：一套通用底座覆盖 **接口 / UI / 性能** 三大测试方向，完整体现测试开发综合能力。
2. **公共能力统一封装**：各业务模块复用底层工具（日志、配置、请求封装），代码低冗余、易扩展。
3. **配置与代码分离**：环境地址、测试账号统一存放于 YAML，杜绝硬编码敏感数据。
4. **工程化支持**：支持命令行灵活调度，可无缝接入 CI 持续集成，实现自动化回归与性能压测。
